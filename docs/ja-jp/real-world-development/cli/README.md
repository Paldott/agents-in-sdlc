**[GitHub Copilot CLI][about-copilot-cli]** を使うと、ターミナルで GitHub Copilot をエージェント型コーディングアシスタントとして利用できます。コードベースの調査、コード生成、コマンド実行、外部ツールへの接続をすべてコマンドラインから行えるため、グラフィカルエディターに切り替えず作業に集中できます。

このワークショップでは、Tailspin Toys の一連のワークフローに取り組みます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、プロジェクトを確認します。
2. 星評価を対象に絞って変更し、ブラウザーでレビューして、最初のプルリクエスト (PR) を手動でマージします。
3. フィルター Issue から始め、Plan モードで進め方を定義し、Autopilot モードで実装してから、Interactive モードでレビューします。
4. リポジトリの指示を更新し、フィルター機能に適用します。
5. 既存の `quality-checks` スキルをカスタマイズし、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーでフィルター機能を確認します。
7. 品質保証 (QA) カスタムエージェントを作成し、要件、カバレッジ、検証の証拠を確認します。
8. フィルター機能全体をレビューし、Agent Merge を使って PR をマージします。
9. コンテキスト、モデル、共有、cloud agent への任意の委任に使う便利なスラッシュコマンドを確認します。

このワークショップでは、星評価用とフィルター機能用の 2 つの PR を作成します。フィルター機能の PR には、指示、スキル、QA プロファイル、テストの更新も含まれます。フィルターと品質に関する作業では、同じ会話とブランチを共有し、各ツールを試しながら作業を積み重ねます。

## 前提条件

このワークショップに参加する前に、次のものを用意してください。

- [ ] **Copilot Student、Pro、Pro+、Business、Enterprise** のいずれかの有効なプランがある GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンドライン操作の基本的な知識

> [!TIP]
> 有料プランを利用していない場合、認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使用するエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise の場合は、管理者が Copilot CLI を有効にしていることを確認してください。
