Explore o GitHub Copilot ao longo do ciclo de vida de desenvolvimento de software por meio de cenários realistas, um aplicativo completo e um backlog compartilhado. Você planejará mudanças, criará código, testará comportamentos, revisará pull requests e gerenciará o trabalho com agentes de forma iterativa.

## Cenário

Você é uma pessoa desenvolvedora recém-chegada ao Tailspin Toys, uma empresa fictícia de financiamento coletivo de jogos de tabuleiro com tema de programação. O backlog da equipe já está registrado como issues do GitHub. Ele inclui funcionalidades como filtragem e paginação, além de melhorias de qualidade, como acessibilidade e padrões de código.

## Escolha seu ambiente

O GitHub Copilot acompanha você no ambiente em que trabalha. Escolha como prefere desenvolver. Cada workshop começa com sua própria configuração e usa o cenário compartilhado do Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente com agentes no terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, Playwright MCP, Agent Merge e comandos práticos de barra.

### [Aplicativo GitHub Copilot][app]

Execute sessões paralelas de agentes, alterne os modos de sessão, colabore em canvases e gerencie issues e pull requests do GitHub no aplicativo para desktop.

### [Agente de nuvem do GitHub Copilot][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente o trabalho, acompanhe o progresso e revise os pull requests que ele abrir.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo de agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
